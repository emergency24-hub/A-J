# A & J Plumbing and Gas Limited website

Open `index.html` in a browser. No server, build tools or internet connection are needed.

Edit the `SITE` block at the top of `script.js` for business details, postcode areas, FAQs and services. Service links use local hash routes (`#service/...`) so they also work when opened from the file system.

The supplied A & J artwork contains different service wording, so the site uses its A & J mark and the provided company name beside it. The included photos are the supplied high-resolution job photos, with separate images selected for the hero and each service. Supplied Gas Safe Register and CIPHE marks are displayed in their original colours.
